# Diretrizes Permanentes do Projeto

- **Preservar Edições do Usuário**: Nenhuma edição ou código existente feito pelo usuário ou acordado anteriormente deve ser sobrescrito, revertido ou modificado, a menos que haja solicitação explícita do usuário.
- **Modificações Cirúrgicas**: Faça edições pontuais, preservando toda a base de código, configurações e estilo visual já estabelecidos.
